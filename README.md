# 🛍️ Zawak

A modern e-commerce web application built with React and Redux, designed to provide an exceptional shopping experience. The app features cart and wishlist management, a quick product view modal, and a clean, responsive user interface.

---

## 🚀 Features

### 🛒 _User-Friendly Shopping Experience_

- Add products to your shopping cart seamlessly.
- Save your favorite products to the wishlist for later.

### 🖼️ _Quick Product Preview_

- Hover over any product to access a "Quick View" modal for instant details.

### 🎨 _Responsive and Modern UI/UX_

- Minimalistic design tailored for a delightful shopping experience.
- Fully responsive across all devices, ensuring accessibility for all users.

### 🔄 _State Management_

- Efficiently managed with _Redux_, making the app scalable and maintainable.

---

## 🛠️ Tech Stack

- _React_: Front-end framework for creating an interactive and dynamic user experience.
- _Redux_: Centralized state management for cart and wishlist functionalities.
- _Lucide-React_: Lightweight and customizable icons.
- _Tailwind CSS_: Custom styling for responsiveness and aesthetic appeal.
